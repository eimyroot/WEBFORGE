# Contributing

Thanks for contributing to WEBFORGE.

- Open an issue for substantial architecture, generation, browser-automation, or component-system changes.
- Keep changes narrowly scoped and avoid unrelated refactors.
- Never commit credentials, secrets, production data, or third-party private content.
- Generated output must remain distinguishable from authoritative source inputs and should be reproducible where practical.

Use the development and validation commands documented in the repository. Run the relevant lint, test, build, and browser checks before opening a pull request.

Pull requests should explain what changed, why, how it was tested, and any compatibility, security, browser, generation, or rollback impact.

By contributing, you agree that your contribution is submitted under the repository's existing license and project terms unless a separate written agreement applies.
