# Architecture

WEBFORGE separates four authorities:

1. **Domain intelligence** — intent, capabilities, patterns, runtime, components, tools.
2. **Deterministic policy** — trust/license/runtime/release hard gates.
3. **Execution adapters** — conditional integration surfaces; never implicit trust.
4. **Evidence** — every verification records a machine-readable receipt.

## Knowledge graph

`COMPONENT → best_for → USE CASE`

`COMPONENT → requires → CAPABILITY`

`COMPONENT → compatible_with → RUNTIME`

`COMPONENT → implemented_by → TOOL`

`COMPONENT → governed_by → POLICY`

`COMPONENT → evidence → REAL RESULTS`
