# WEBFORGE UNIVERSAL 7.0

WEBFORGE UNIVERSAL is an Adaptive Web Product Compiler. The compiler does not require every project to match a fixed website archetype. It decomposes a brief into a domain model, Website Genome, product capabilities, experience model, Design DNA, composition, connectors, runtime and evidence.

## Compiler pipeline

```text
BRIEF
  -> DOMAIN INTELLIGENCE
  -> WEBSITE GENOME
  -> PRODUCT / CAPABILITY INTELLIGENCE
  -> EXPERIENCE INTELLIGENCE
  -> DESIGN DNA
  -> COMPOSITION INTELLIGENCE
  -> CONNECTOR + PLUGIN RESOLUTION
  -> RUNTIME FORGE
  -> BROWSER QA
  -> PREVIEW
  -> APPROVAL
  -> PRODUCTION
```

## Website Genome

The genome captures purpose, audience, content, interaction, visual mode, application depth, data depth, trust burden, media intensity, conversion intensity, novelty and locality. It is reconciled with the resolved capability graph so an initially vague brief can become an application-grade architecture when capabilities such as identity, persistence or workflow require it.

## Novel Domain Compiler

A novel domain is not mapped to PASS just because a generic website can be rendered. Novel briefs are decomposed into entities, user jobs and capabilities. Supported capabilities may be compiled; adapter capabilities remain CONDITIONAL; unsupported capabilities remain UNRESOLVED. Example: an industrial 3D configurator resolves `product.configuration.3d` as UNRESOLVED and blocks production eligibility.

## Universal resolution invariants

- UNKNOWN != PASS
- MISSING != PASS
- UNVERIFIED != PASS
- connector selection does not authorize external writes
- plugin selection does not authorize installation
- generated content and procedural media are provisional until approved
- production requires real connector/runtime/media/content evidence and explicit approval
